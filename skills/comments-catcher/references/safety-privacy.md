# 安全与隐私

## 允许的使用方式

- 读取用户正常可见的公开评论。
- 复用用户主动登录的 WebBridge 浏览器会话。
- 以保守间隔翻页，并允许用户设置更慢的速度或更小的采集上限。
- 在本地保存完成任务所需的最少字段。

用户应确认其使用方式符合适用法律、站点条款、组织政策与研究伦理要求。

## 明确禁止

本技能、Agent 和采集器都不得：

- 求解、点击或自动处理 CAPTCHA。
- 绕过登录、权限、付费墙、地区限制、风控或其他访问控制。
- 轮换代理、建立代理池或用 IP 变化规避限制。
- 伪造浏览器指纹、设备标识、行为轨迹或客户端环境。
- 逆向、生成或重放私有签名与未授权接口请求。
- 读取、导出、打印、记录、上传或向用户展示 Cookie、令牌、认证头、Local Storage、Session Storage 或密码。
- 要求用户把 Cookie 或令牌粘贴到聊天、命令行参数、配置文件或输出文件。
- 采集私密页面、未授权账号数据或与任务无关的个人信息。

“研究”“测试”“本人账号”“本地环境”等表述不会改变这些边界。

## CAPTCHA 与登录处理

1. 检测到 CAPTCHA 后立即暂停或安全退出。
2. 告知用户在同一个 WebBridge 浏览器会话中手动处理。
3. Agent 不点击验证码，不识别验证码内容，不调用第三方打码服务。
4. 用户明确确认已处理后，才可按正常间隔重试。
5. 登录失效时采用同样的人工流程，不自动注入凭据。

## 数据最小化

- 默认只保留评论分析所需字段。
- 不在输出中保存认证材料、完整请求头或浏览器存储。
- 对用户标识、昵称和头像等字段按实际任务需要取舍。
- 输出文件应存放在用户明确或项目约定的目录中，不自动上传到第三方服务。
- 调试日志应避免包含完整页面快照、个人资料详情或可复用的会话信息。

## 保留与删除

- 任务完成后向用户说明输出位置。
- 临时文件应在正常退出和错误退出时清理。
- 用户不再需要数据时，应删除本地输出及其备份。
- 将数据提交到 Git 前先检查隐私与授权；仓库默认忽略常见采集输出路径。

## 速率与平台负载

默认等待间隔为 5 秒。不得通过并发放大、代理轮换、指纹伪造或签名逆向规避平台限制。出现 429、明显风控提示或连续异常响应时，应停止并稍后由用户决定是否重试，而不是提高请求强度。
